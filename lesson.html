Introduction to HTML

HTML stands for HyperText Markup Language. It is the standard language used to create and structure content on websites.

What is HTML?

HTML provides the basic structure of a webpage. It allows us to create headings, paragraphs, images, links, lists, tables and many other elements.

Basic HTML Structure

Every HTML document normally starts with a document declaration followed by the HTML structure. 

<!DOCTYPE html>

<html>

<head>

    <title>
        My First Website
    </title>

</head>

<body>

    <h1>
        Hello World!
    </h1>

    <p>
        Welcome to my website.
    </p>

</body>

</html>

Important HTML Elements

  • <h1> — Creates a heading.
  • <p> — Creates a paragraph.
  • <a> — Creates a hyperlink.
  • <img> — Adds an image.
