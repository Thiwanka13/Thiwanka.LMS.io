HTML Structure

In this lesson, you will learn about the basic structure of an HTML document and how different HTML elements work together.

HTML Document Structure

An HTML document normally contains a document type declaration, an html element, a head section and a body section.

The HTML Element

The html element is the root element of an HTML document. All other elements are placed inside it. 

<!DOCTYPE html>

<html>

    <head>

        <title>
            My Website
        </title>

    </head>


    <body>

        <h1>
            Welcome
        </h1>

        <p>
            This is my website.
        </p>

    </body>

</html>

Important Sections

  • <html> — Root element.
  • <head> — Contains page information.
  • <title> — Defines the page title.
  • <body> — Contains visible page content.
